# 更新日志

## 0.1.2 — 2026-11-08

### 修复
- 奖励广告「关闭」误点：屏幕角落的关闭按钮不再被当成「奖励中断弹窗」的关闭，消除「关闭 → 暂未获得奖励 → 继续观看 → 又关闭」的死循环。
- 「继续观看」延迟出现：弹窗消失后才在底部出现的「继续观看」小字，现在也能被识别并点击，恢复播放与奖励；同一目标 2 秒内不重复点击。
- 「暂未获得奖励」弹窗出现时直接结束本轮判断，不再落入关闭逻辑。
- 清空日志时同时重置「今日 / 累计」跳过计数。
- 日志列表显示应用名称，点进详情才显示包名。

## 0.1.1 — 2026-11-08

以测试版形式发布，跳过与奖励保护规则仍在持续验证。

### 修复
- 奖励广告提前关闭：奖励到手前不再点右上角关闭图标与「关闭」文案，避免出现「暂未获得奖励」。
- 「暂未获得奖励」弹窗：识别后点「继续观看」恢复倒计时，不再继续误点关闭。
- 强制浏览弹窗：广告本身带奖励承诺时不再退出广告，等待视频播完正常领奖。
- 哔哩哔哩视频卡片：点开「三个点」菜单后的「不感兴趣 / 不感兴趣：当前视频 / 选择不感兴趣原因」不再被当作广告关闭项，仅在检测到广告标识时才执行「关闭此条广告」。
- 横屏游戏：屏幕宽高改为按当前显示方向读取，修复横屏下角标、跳过文案与倒计时位置判断错乱。
- 连点：每次点击后进入硬冷却，同一规则同一应用 10 秒内最多触发 4 次；点击后的复检也延后到冷却结束。

### 调整
- 点击冷却默认值由 400 ms 提升到 1200 ms，可调范围 400–3000 ms。
- 关于页新增「测试版 · 可能存在 Bug」说明卡片，概览页标题旁新增测试版标签。

### 其他
- 移除 ML Kit 依赖带入的 `INTERNET` 与 `ACCESS_NETWORK_STATE` 权限，真正做到完全离线、零流量。
- 关于页「网络」一栏描述与实际权限保持一致。

## 0.1.0 — 2026-11-08

首个公开发布版本。

### 自动跳过
- 开屏 / 插屏广告：识别「跳过」「跳过广告」「关闭广告」等文案、`skip_button` / `ad_close` 等控件 ID、右上角倒计时数字，节点不可点击时按坐标兜底点击。
- 启动 6 秒内并行检测：控件树与离线 OCR 同时工作，任一路命中立即跳过。
- 图片识别（OCR）：Android 11+ 截取右上区域，用 ML Kit 中文模型离线识别「跳过」并点击。
- 小弹窗广告：识别带「广告」标签的浮层并点关闭。
- 信息流广告：识别抖音等平台的「广告」小标签，自动上滑跳过。
- 视频广告自动静音：识别音量图标（含无文字的角标图标）并点击静音。

### 奖励广告保护
- 识别「看视频领奖励」类广告，默认显示悬浮球，点一下才跳过，避免误跳丢奖励。
- 误跳时自动点「继续观看」撤回退出。
- 「关闭广告后将无法获得奖励」确认框：绝不点关闭；没有撤回按钮时进入冷却，避免反复误触。
- 「去浏览 X 秒减广告时长」等强制浏览弹窗：有「继续看视频」时点它继续播放，没有返回入口时直接退出广告。
- 视频播放完成、出现结束卡片后自动识别并关闭。

### 通知
- 跳过提示：静默通知，固定单条折叠，显示今日跳过次数，不弹横幅、不响铃。
- 运行通知：常驻、可单独关闭，带「暂停拦截 / 开启拦截」手动开关。

### 应用
- 概览页：运行状态、暂停开关、今日 / 累计统计、后台保活入口。
- 规则页：倒计时识别、控件 ID、描述文本、手势兜底、激进模式、点击冷却、应用黑名单、奖励广告模式等。
- 日志页：记录每次识别与点击的时间、包名、命中内容、规则与结果，支持查看详情。
- 关于页：AI 生成提示、开源组件许可证、内置更新日志（Markdown 渲染）、GitHub Issue 反馈入口。
- 完全离线：不申请 INTERNET 权限，不上传任何数据。

### 兼容性
- 最低支持 Android 10（API 29），适配 Android 15 / 16。
- 无障碍服务名称：闪退广告。
